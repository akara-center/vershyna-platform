# Дані першого прототипу

Трекер зберігає формат версії 4. Додаткове поле `pilot` має власну версію 1. Попередні JSON без цього поля підтримуються через явний імпорт. Імпорт перевіряє обидві частини й зберігає датовану копію попереднього стану. Свіжі профілі отримують вигаданий приклад із `dist/demo.js` і короткий текст бачення в `dist/state.js`. Профілі з імпортом використовують імпортовані місії.

- Завершення фіксується у UTC, а в підсумках групується за календарними днями Києва. В історії зберігаються назви на момент виконання. Перейменування, перенесення, архів або кошик не прибирають зафіксовану історію. Скасування завершення позначає попередній запис скасованим, підсумок його виключає. Старі завершення без дати мають окрему секцію.
- Оцінка має дату Києва, ID показника й незмінну шкалу. Прототип дозволяє одну оцінку на день для кожного показника. Повторне збереження цього дня оновлює значення. Пропуск не створює запису.
- Бачення зберігає попередні версії. Вибір пов’язаного проєкту дає перехід до його дерева.
- Звіт містить добровільно відмічені записи, період і дату підготовки. Плановий блок ґрунтується на явно введених датах. Збережений звіт є знімком тексту, без статусу доставлення.

- Маршрут додає необов’язковий масив `pilot.goals`. Ціль має стабільний ID, назву, пояснення сенсу, очікувану зміну, критерії, ID проєктів і проміжні результати. Кожен проміжний результат має власний ID, назву та ID проєктів. Одна й та сама місія може бути пов’язана з кількома результатами. Старі поля цілі, критеріїв, проміжного результату й проєкту читаються як одна ціль. Старий вільний текст переноситься цілим.
- Редакція маршруту зберігає попереднє бачення, цілі, результати й назви доступних на той час проєктів. Вилучення цілі чи результату створює попередню версію та не видаляє проєкт. Посилання на архівний проєкт відкриває його перегляд. Недоступні посилання можна зняти в редакторі.
