# Пакет стартового маршруту від коуча

У «Співпраця з коучем» → «Від коуча» → «Додати пакет маршруту» клієнт може відкрити приклад, вибрати файл або вставити JSON. «Переглянути пакет» показує зміст. «Додати до мого маршруту» створює датовану копію попереднього стану й додає пакет.

Формат версії 1 наведено в [тестовому файлі](../dist/example-coach-route.json). Поля верхнього рівня: `type`, `version`, `id`, `author`, `source`, `vision`, `goals`, `projects`, `materials`. Для окремого пакета потрібен новий ID. Автор і джерело — підпис того, хто підготував файл. Максимум 256 КБ.

- `vision` може бути порожнім об’єктом. Нові поля додаються до бачення. Заповнені клієнтом поля мають пріоритет.
- `goals` мають `id`, `name`, необов’язкові `why`, `change`, `criteria`, `projectIds` і `milestones`. Проміжний результат має `id`, `name`, необов’язковий `projectIds`. Посилання ведуть до проєктів у пакеті.
- `projects` мають `id`, `name`, `goal` і `steps`. Крок має `id`, `name`, `result`, `minutes`, `xp` і, за потреби, `children`. Початкові кроки додаються невиконаними. ID перетворюються на нові локальні ідентифікатори.
- `materials` — картки з `kind` (`observation`, `question`, `suggestion`), `title` і `text`. У пакеті лишаються тільки відомості, які слід передати клієнту.
- Повторне застосування того самого ID блокується. Копію перед останнім пакетом можна завантажити в «Дані» та відновити через наявний імпорт JSON. Відновлення копії замінює стан на момент її створення.

На статичному пілоті пакет зберігається в браузері. Клієнт сам його застосовує. Спільний доступ до даних потребує серверної моделі.
