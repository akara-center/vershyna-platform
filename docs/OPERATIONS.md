# Запуск і публікація

Локальний запуск і тести наведено в README і TESTING. Збірка статична, файли застосунку в `dist/`. Для GitHub Pages використовується `.github/workflows/pages.yml`. У параметрах репозиторію **Settings → Pages → Build and deployment → Source** має бути **GitHub Actions**. Workflow перевіряє синтаксис і запускає тести перед завантаженням `dist/`.

Експорт і відновлення виконуються через «Дані». Перед відновленням програма робить локальну датовану копію. Відкат коду через Git не відновлює дані з браузера.
