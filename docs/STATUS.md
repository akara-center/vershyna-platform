# Перша тестова збірка

Трекер перенесено перед додаванням нових екранів, зі збереженням наявних функцій. Є чотири розділи, тестова місія, редаговане бачення з історією, датовані результати, добровільні показники та підготовка звіту коучу.

Обсяг наступних етапів: повна модель цілей і персональної графіки, статус неактуальності, імпорт початкового маршруту й матеріалів коуча, налаштування співпраці та контактів, серверні акаунти, авторизація й синхронізація пристроїв. Актуальний план у PLAN.md. Приймання належить Катерині.
