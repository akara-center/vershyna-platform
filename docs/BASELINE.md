## Повторення браузерного порівняння

Потрібні Git, Node та Python або інший статичний сервер. У локальному клоні:

```text
git fetch origin
node scripts/prepare-browser-check.cjs origin/backup/pre-structure-2026-11-22
python3 -m http.server 8001 --bind 127.0.0.1 --directory .browser-check
```

У Windows замість python3 можна `py`. Відкрити http://127.0.0.1:8001/ → «Перевірити всі сценарії» → очікувати PASS. Скрипт перезаписує лише службову папку .browser-check. Для іншої бази передати її Git ref аргументом після назви скрипту. Базова й поточна версії готуються автоматично.

**Використовувати окремий локальний порт/origin без особистих даних:** тест навмисно записує синтетичний summit-v1 у localStorage цього origin. Не запускати на бойовому домені та на локальному origin з потрібним прогресом. Папка тесту не публікується на GitHub Pages; workflow публікує лише dist.

Порівняння суворе: навмисна зміна вигляду дасть FAIL. Для нової погодженої бази вказати коміт попереднього етапу й переглянути очікувані відмінності. Контроль не підмінює ручну оцінку зручності й читабельності.

Перед публікацією також виконати `node scripts/check-syntax.cjs` і `node --test tests/*.test.cjs`; перевірити відносні шляхи під /vershyna/. Після push — успішний Actions для відповідного SHA та жива сторінка.

## Структурний етап

Резерв до структурних змін: [backup/pre-structure-2026-11-22](https://github.com/akara-center/vershyna/tree/backup/pre-structure-2026-11-22), SHA `cc35f2c72a7129cfd99b8bbc5e11232c579a6586`. Окремі коміти: HTML-шаблони; поділ JS; CSS і документація.

40 детермінованих комбінацій станів/форм у VM дали побайтово однаковий HTML. AST 45 функцій при рознесенні між файлами збережені; таймер винесено з обробника у startTimerFor(next). Шість тестових файлів Node проходять у новому порядку скриптів. CI перевіряє синтаксис кожного dist/*.js.

Поточний браузерний набір: 132 порівняння (6 ширин × 2 теми × 11 екранів/меню/форм) плюс 16 порівнянь порожнього, завершеного, архівного стану та вкладеного курсу — разом 148. Зіставляються текст, значення полів, геометрія та всі обчислені CSS-властивості. Кожен iframe активується перед зчитуванням, щоб однаково перевіряти focus-visible. Анімації вимикаються лише в тестовій сторінці для стабільного порівняння. Поведінкові перевірки включають запуск/паузу таймера без нарахування XP.

CSS: видалено 20 перекритих декларацій, перенесено 10 доведено сумісних для зведення повторних селекторів; 3420 потенційно конкурентних пар зберегли порядок з урахуванням specificity, important, груп властивостей і media. Не зводити всі повтори селектора в одне місце механічно: умовні стилі та їхня черговість мають значення.

Цей етап не додає синхронізацію вкладок/пристроїв, service worker або збереження таймера після reload. Особистий прогрес не використовується в перевірках.
