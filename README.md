# Вершина 2.0

Клієнтський трекер і робочий прототип на синтетичних даних. Основні розділи — «Мій день», «Мій шлях», «Мій прогрес» і «Співпраця з коучем».

[Відкрити тестову Вершину 2.0](https://akara-center.github.io/vershyna-platform/)

## Запуск на комп’ютері

Потрібен Python 3. У PowerShell із каталогу репозиторію виконай `py -m http.server 8080 --directory dist` і відкрий [localhost:8080](http://localhost:8080/). Зразок починається з вигаданої місії про прогулянки. Збереження прив’язане до браузера й адреси застосунку. Для перенесення тестових даних скористайся «Дані» → JSON.

## Серверна версія

Облікові записи, синхронізація, кабінет коуча і підключення Google Calendar запускаються через Node.js 24 або Docker. [Запуск і розгортання](docs/SERVER.md).
